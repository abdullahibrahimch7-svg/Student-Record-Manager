# Student Record Manager

A **Python-based Student Record Management System** with a graphical user interface built using **Tkinter**.

This project allows you to manage students, subjects, marks, percentages, and student performance graphs. Student records are stored persistently using a JSON file.

## Features

* Add students
* Add subjects and marks
* Search student records
* Update student information
* Delete students
* View all students
* Calculate overall percentages
* Generate student performance graphs
* Store data using JSON
* Graphical User Interface with Tkinter
* Enter-key navigation
* Full-screen and minimize controls
* Input validation and error handling

## Technologies

* **Python**
* **Tkinter**
* **JSON**
* **Matplotlib**

## How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/abdullahibrahimch7-svg/Student-Record-Manager.git
```

### 2. Open the Project

```bash
cd Student-Record-Manager
```

### 3. Install Matplotlib

```bash
pip install matplotlib
```

### 4. Run the Application

```bash
python student_record_manager.py
```

## Student Performance

The application calculates individual subject percentages and an overall percentage based on total and obtained marks.

It can also generate a performance graph using Matplotlib.

The generated graph is saved as:

```text
student_performance_graph.png
```

## Data Storage

Student records are saved in:

```text
students_data.json
```

The application automatically loads existing records and saves changes to the JSON file.
